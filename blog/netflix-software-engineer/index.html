百工百業project#18：網飛軟體工程師 Netflix Software Engineer

擁有全球3.25億的最大串流影音平台，要如何吸引使用者在平台上駐足，畫面、排版上的呈現與設計都需要靠這個職位協助，歡迎光臨網飛軟體工程師的一天👋

來點簡單的自我介紹

嗨我是一個不安份的工程師，升大學一股衝動到香港唸書，畢業一個機緣就來到美國，全部都跟預想的不一樣。工作不開心就跳槽，之前待過 pre-馬斯克的Twitter（幸福企業），獨角獸 Databricks，到現在的Netflix。可能過一兩年就想從工程師畢業，因為 AI把我喜歡做的事情做走了，軟體工程大概只會剩下我不喜歡的差事（aka 說話）。喜歡學習新東西，隨遇而安，我在哪裡做什麼事想交給時間。

工作秘辛

別人最常問你關於這份工作的一個問題是？

跟你買Netflix帳號會比較便宜嗎？

👉 答案是：答案是：不會，大家請照樣付費😂

請介紹一下你所在的組是在做什麼呢？

我待的組叫做Evidence Engineering，主要是呈現在Netflix App所有看的見視覺資訊，包含預覽圖像、預覽影片、文字描述、TOP10、即將上架等等資訊的呈現（如下圖的紅框和圖片），這些資訊的呈現會因人而異，用意是吸引使用者點進去玩遊戲或看影劇

描述一下你的一天——你通常在做什麼？

跟普遍工程師應該都蠻像的，前天會先看一下明天有哪些會議要參加，有時會收到主管的任務派工通知，身上同時會有4-5個專案在身，就必須跟各專案PM討論溝通，確保專案可以如期如質完成。

我現在負責的主要是遊戲相關，做的就是用戶端的呈現。分享最近做的幾個有趣任務：

  • 目前正在架構遷移的任務，原本遊戲的資料架構是做在比較舊的架構上，隨著遊戲邏輯越來越複雜，以前的設計不夠彈性，所以決定把遊戲從舊架構改到新架構上
  • 即將上架coming soon：以前即將上架只有支援影片相關；現在也有支援遊戲相關了

  • 遊戲主看板：大家最熟悉的就是首頁一進去會有個超大的主看板，會放當季最紅的電影或是影劇介紹，現在也有專門聚焦在遊戲出一個新的遊戲主看板

💡科普知識｜Netflix的遊戲有分成雲端遊戲&手機遊戲，台灣目前只有手機遊戲，雲端遊戲的話主要是以歐美市場居多。

AI誕生之後，有應用在什麼地方嗎？

1️⃣設計架構討論｜當今天接到的任務比較大型改動且沒有標準解決方法的時候，就會跟AI討論可行方向，再透過邊討論邊修正作法

2️⃣Debug跟測試｜以前需要人工自己寫一段程式去測試，現在就是請AI幫忙寫程式做Debug跟測試，方便很多

好奇問Netflix會有「猜你也喜歡」是怎麼出現在使用者介面的呢？

其他組別有專門負責做相關演算法開發的，他們算完之後會提供一組做好的演算法資料庫 → Evidence Engineering會去接演算法的結果+合成前端邏輯 → 呈現出最後使用者看到的長相

如何判斷演算法推薦的效果好壞？
  • 主要會用A/B test 去比較兩組在關鍵指標上的表現差異，判斷新版本是否真的比較好。A組（控制組）會用原本的演算法、B組（對照組）是新的演算法，後台會去收集各組使用者的資料，像是：影片停留時間、影片點擊率、用戶活躍程度等等標準的追蹤指標。
  • 實驗跑完後就會生成報告比較控制組&對照組，新的演算法整體表現有無顯著變化，如果有些重要的追蹤指標進步了，就代表說這是一個有進步的演算法，就可以適合推行。
  • 這當中很重要的一點是這個實驗設計所找的人都會是隨機的，比如今天我要針對美國用戶做演算法測試，就得先設定參數決定要找多少百分比的美國使用者出來做實驗，這些使用者都會是隨機選定的，他們也不會知道自己正在被實驗中。

這份工作最喜歡的地方、以及最不喜歡的地方各是什麼？

喜歡的地方

可以做接近user端的東西

因為之前的工作是做內部的雲端資源整合平台，提供給內部的工程師使用，所以無法看見自己的成果有實際畫面的產出；現在做的事情就是可以看得到產出，做的東西都是給使用者真的可以用得到、看得到的東西，相比之下就比較有成就感。

不喜歡的地方

沒有固定制度

因為公司很自由，所以沒什麼規範，這點容易讓新進同仁會感到無所適從。舉個例子來說一般正常要release產品的話，各公司自己會有些規範，但在這裡就是只要你有辦法做出來什麼方法都可以，是所以問10個人可能就會得到10種解法，要自己想辦法。

分享一件工作上讓你挫折的事情

練習讓人聽得懂的溝通｜因為以前的工作不太需要這麼多的溝通，但在Netflix大家的溝通頻率是很高的，所以剛加入的時候，觀察到大家都很勇於發言、英文都很流利，溝通能力很好，就會擔心自己是否不夠厲害，有一點冒牌者症候群（Impostor Syndrome）

你認為要入門這個領域，需要具備哪些基本能力？

⭐⭐⭐獨立解決問題&溝通能力｜不同專案會對到各種不同人，像是會遇到PM來討論需求，要可以跟對方來來回回，並且在時間內把東西做出來。所以要會問對問題，清楚知道讓對方你的進度，這點在Netflix被訓練得很紮實。

對於第一次想踏入這個領域的人，你有什麼建議？

1️⃣簽證議題｜Netflix有個著名文化是Keeper Test，就是主管要隨時問自己，這個下屬如果現在此時此刻提離職，你會不會想挽留他？如果答案是No，那這個下屬就應該要被炒掉。在Netflix這一年半的期間也看過不少人被資遣，整組解散的也有。所以如果簽證不穩定，遇到這種狀況就會很緊張，但假如你工作能力很好的話，就不用擔心被資遣！

2️⃣技術偏舊｜Netflix裡面的技術滿多是滿落後的，如果是想學新技術，可以去些新穎的公司

曾經有幸去總部參觀，外商公司福利是真的嘆為觀止，公司走廊有可以免費拿所有Apple的配件的櫃子，甚至連拿充電線或是鍵盤螢幕通通不用錢⋯但同時這次訪問後也理解到這裡是殘酷的生存之戰，在Netflix上班一定要拿出對應的能力，畢竟是目前訂閱戶最多的串流影音平台龍頭（全球Netflix用戶有約3.25億人，也就是說訂閱費只要漲1美金，就可以增加3.25億美金營收🤯）
